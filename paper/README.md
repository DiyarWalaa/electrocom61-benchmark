# Paper

LaTeX source. Figures and tables are **pulled in by reference**, never pasted.

## Compiling

```bash
cd paper
pdflatex main
bibtex   main
pdflatex main
pdflatex main
```

Three `pdflatex` passes: the first writes the `.aux`, `bibtex` resolves the
bibliography, and the last two settle cross-references and citations. A single
pass leaves `??` where every `\ref` and `\cite` should be.

`latexmk -pdf main.tex` does the same in one command if it is available.

## The document class is provisional

`main.tex` uses `article` so the draft compiles anywhere. A venue template will
replace it.

**Nothing outside `main.tex` should need to change when it does.** The section
files carry no preamble, no class-specific commands and no formatting
assumptions — only `\section`, `\subsection`, prose, `\ref` and `\citep`.
Switching class should mean editing the preamble and nothing else.

Two habits keep that true:

- **Reference by label, never by number.** `Table~\ref{tab:main-results}`, not
  "Table 4". A typed number is wrong the moment a table is inserted before it.
- **Leave `\graphicspath` as the only place the figure directory is named.** It
  points at `../figures/`, so figures are included by filename alone.

## Figures

Generated by `scripts/make_figures.py` into `figures/`, as PDF for the paper and
PNG at 300 dpi for previewing. Include the **PDF**:

```latex
\begin{figure}[t]
  \centering
  \includegraphics[width=\columnwidth]{f5_published_vs_corrected.pdf}
  \caption{...}
  \label{fig:published-vs-corrected}
\end{figure}
```

No path and no extension guessing: `\graphicspath` in `main.tex` supplies the
directory.

**Captions are not drawn into the images.** Each figure's caption text is
generated with its numbers and printed by the build; ready-to-paste `\caption{}`
blocks for all five figures are in `figures/README.md`. Set the caption in
LaTeX so it wraps to the real column, uses the document font, and reaches
`\listoffigures` and cross-references.

Available: `f1_class_instance_counts`, `f2_capture_group_composition`,
`f4_tau_sweep`, `f5_published_vs_corrected`, `f6_accuracy_vs_latency`, plus the
two audit-phase exhibits `near_duplicate_pair` and `split_verification_sheet`
(PNG only). `figures/README.md` maps every one to the script and run folder that
produced it.

## Tables

Generated by `scripts/make_tables.py` into `tables/`, one `.tex` per table, each
a complete `table` (or `table*`) float with its own `\caption` and `\label`.
Pull one in with:

```latex
\input{../tables/t4_main_results}
```

Do not copy the rows into a section file. The whole point is that a table is
regenerated from its committed source and the paper picks up the new numbers on
the next build.

| File | Label | Contents |
|---|---|---|
| `t1_unevaluable_classes` | `tab:unevaluable-classes` | the 15 classes with no valid or test instances |
| `t2_split_properties` | `tab:split-properties` | published vs corrected split |
| `t3_training_config` | `tab:training-config` | configuration and its provenance (`table*`) |
| `t4_main_results` | `tab:main-results` | accuracy, both splits, five models |
| `t5_efficiency` | `tab:efficiency` | params, GFLOPs, latency, FPS |
| `t6_latency_breakdown` | `tab:latency-breakdown` | pre / inference / post |

All six use `booktabs`, loaded in `main.tex`. `t3` is a `table*` and spans both
columns; it will need a two-column class to sit correctly.

## Regenerating

```bash
python scripts/make_figures.py         # figures/
python scripts/make_tables.py          # tables/
python scripts/check_figures_readme.py # integrity of figures/README.md
```

Every value in both is read from a committed CSV or JSON. Neither script types a
number. Each writes a run folder under `runs/` recording the SHA-256 of its
inputs, so any figure or table can be traced to the data that produced it.
